# Python Data Analysis Project

## 📌 Overview
This project analyzes a retail transaction dataset containing over **45,000 records**. The dataset includes customer details, product categories, brands, ratings, and purchase information. The goal is to understand customer behavior, sales trends, and product performance using Python.

---

## 📊 Dataset Description
The dataset (`cleaned.csv`) contains the following columns:

| Column | Description |
|------|------------|
| item_id | Unique product identifier |
| user_id | Unique customer identifier |
| rating | Customer rating |
| timestamp | Transaction timestamp |
| gender | Customer gender |
| category | Product category |
| brand | Product brand |
| year | Year of purchase |
| month | Month of purchase |
| quantity | Number of items purchased |
| unitprice | Price per unit |
| amount | Total transaction value |

---

## 🛠️ Tools & Technologies
- Python 3  
- Jupyter Notebook  
- pandas  
- numpy  
- matplotlib / seaborn  

---

## 🔍 Analysis Performed
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Sales trends by year and month  
- Customer behavior analysis by gender and ratings  
- Product and brand performance analysis
